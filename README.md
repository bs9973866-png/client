# NIGHTFALL — Minecraft 1.21.4 Fabric Client

Custom client-side Fabric mod for Minecraft 1.21.4 and Java 21.

## Build and download
Open **Actions → Build NIGHTFALL**. The workflow builds the JAR and uploads an artifact named `nightfall-minecraft-1.21.4`. Download that artifact from the successful workflow run.

See [README_NIGHTFALL.md](README_NIGHTFALL.md) for features and installation instructions.
